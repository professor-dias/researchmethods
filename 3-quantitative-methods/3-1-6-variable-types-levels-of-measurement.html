Variable Types

🔑 The Four Levels, At a Glance

In 1946, Harvard psychologist Stanley Smith (S.S.) Stevens argued that all measurement falls into one of four levels. They're not arbitrary labels — each one tells you exactly which math is safe to do with the numbers:

Nominal
Floating, no line at all — just categories
Ordinal
On a line, in order — but gaps are uneven
Interval
Evenly spaced — but "0" just floats mid-line
Ratio
Evenly spaced — and "0" is the true start

Nominal: blood type, Pokémon color  ·  Ordinal: pain scale, evolution stage  ·  Interval: temperature, battle stat levels (Attack/CP can read 0, but that's a baseline, not "zero power")  ·  Ratio: height/weight, ER visits.

Notice the last two look almost the same — both evenly spaced — but interval's line keeps going past "0," while ratio's line starts there. That's the whole difference between "0°C" (not "no temperature") and "0 siblings" (really none).

🔁 What Is It Now?

Stevens' framework is great for theory, but modern data work chooses charts and statistical tests based on a slightly different, more practical split. Here's how the same variables get re-sorted:

Stevens (1946)
Modern practice
Nominal
→
Nominal (3+ categories)
↪
Binary (2 categories)
Ordinal
→
Ordinal (3+ ordered categories)
Interval
→
Continuous (measured on a continuum)
Ratio
→
Discrete / Count (whole numbers only)
⤴
Continuous (when measured, not counted)

What actually changed, in three notes:

1. Interval mostly disappears. Whether a variable has a true zero rarely changes which chart or test you'd use, so interval and ratio both just become "Continuous."

2. Binary earns its own category. A yes/no variable is technically 2-level nominal — but it powers so much of health research (disease vs. no disease) that it gets its own toolkit: proportions, odds ratios, logistic regression.

3. Count breaks off from Ratio. Whole-number counts (visits, siblings, symptoms) are often skewed and can't go below zero — they need their own models (like Poisson regression) and their own visuals.
